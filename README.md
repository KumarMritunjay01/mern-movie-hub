# mern-movie-hub
A full-stack MERN movie application that allows users to browse movies, view details, and manage content

# Features
    1. User
        View movies (IMDb Top Movies)
        Search movies by name or description
        Sort by rating, name, release date, duration
        Pagination support

    2. Admin
        Add new movies
        Edit movie details
        Delete movies
        Role-based access control

# Tech Stack
    1. Frontend
        React.js
        Material UI
        React Router
        Axios

    2. Backend
        Node.js
        Express.js
        MongoDB + Mongoose
        JWT Authentication

# Authentication
    JWT-based authentication
    Role-based access (Admin/User)
    Protected routes
